# Certas — unduhan

Peta lapangan offline untuk tambang: buka GeoPDF (Avenza, Global Mapper, ArcGIS, QGIS, Resilire), GPS terkalibrasi, markup dan foto, import DXF, ekspor DXF/KMZ/CSV/GeoPackage.

**Unduh versi terbaru:** https://certas.paatrickwl.workers.dev/download

Repo ini hanya berisi file APK rilis. Kode sumber bersifat privat.

## Pasang di Android
1. Unduh `Certas-<versi>-arm64.apk` (HP Android 2017 ke atas). HP lama 32-bit: `armv7`.
2. Buka file, izinkan "Instal dari sumber ini" bila diminta.
3. Buka Certas → Import peta.
